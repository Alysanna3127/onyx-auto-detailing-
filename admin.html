ONYX Owner Guide

Practice updating your website without writing code. GitHub handles your login and permissions. This page is an instruction hub, not a password-protected admin panel.

1. Sign in

Open the repository and sign in to the authorized GitHub account. Only accounts with repository write access can save changes.

Open GitHub repository

2. Change service names or descriptions

Open content.json, tap the pencil icon, edit the words inside quotation marks, then tap Commit changes. Keep the commas, brackets, and quotation marks intact.

Edit website content

3. Upload photos

Upload JPG, PNG, or WebP files into the images folder in GitHub. Then edit content.json to change the matching gallery image value to images/your-photo.jpg. Commit both changes. Avoid spaces in filenames.

Open images folderEdit photo list

On iPad Safari: open the images folder, choose Add file → Upload files. If Add file is hidden, use the three-dot menu.

4. Publish and check

Once you commit, Netlify should automatically redeploy the site from the main branch. Wait for Published status and refresh the website.

Open NetlifyOpen live website

Important limitations

This is a working GitHub-based editing workflow, not a custom upload dashboard. Editing photos requires two steps, and the quote form remains a demonstration. A polished client login would require a separately configured CMS and authentication service.
